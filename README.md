# Кэшлис — публичные сборки

Официальные Android-сборки и файлы обновлений Кэшлиса. Исходники приложения
в этом репозитории не публикуются.

[Сайт Кэшлиса](https://cashbackplan.ru) · [Скачать сборку](https://github.com/quick6response/cash-lis/releases)

В каждом Android-релизе:

- `cashlis-<version>.apk` — самостоятельное приложение для ручной установки;
- `.sha256` — контрольная сумма соответствующего файла;
- `mobile-update.json` — версия, Android versionCode и официальная ссылка на APK;
- `.aab` — если выпущен кандидат для магазина; напрямую на телефон не устанавливается.

Тестовые версии помечены Pre-release. APK использует production API
`https://cashbackplan.ru/api`; Expo Go и Metro для него не нужны.

Скачайте APK на Android, разрешите установку из выбранного браузера и подтвердите
обновление. Для обновления поверх старого приложения нужна одинаковая подпись.
Не удаляйте приложение только ради обновления.

Версии с поддержкой публичного репозитория проверяют APK в настройках приложения.
Если установленная версия ещё обращается к старому источнику, сначала обновите её
вручную из этого репозитория. На iPhone APK не устанавливается — нужен TestFlight/App Store.
